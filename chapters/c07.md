## 根数界与不可约性判别

:::::{container} statement-box theorem
:name: c07-statement-004

::::{container} source-line source-label
:name: p050-l01

定理 7.2
::::

::::{container} source-line
:name: p050-l02

以下记 $n=\deg f$。

（度数紧箍咒）给定 $f \in {\mathbb{F}}[ x], \deg(f) > 0.$ 如果 $b_{1},b_{2},\cdots,b_{m}$ 是 $f$ 在 $\mathbb{F}$ 中的 $m$ 个不同的根, 其对应的重数分别为 $k_{1},k_{2},\cdots,k_{m}$, 那么
::::

::::{container} source-line
:name: p050-l03

$$
(x-b_1)^{k_1}(x-b_2)^{k_2}\cdots(x-b_m)^{k_m}\mid f.
$$
::::

::::{container} source-line
:name: p050-l04

特别地$, k_{1} + k_{2} + \cdots + k_{m} \leq n,$ 从而 $f$ 在 $\mathbb{F}$ 中至多有 $n$ 个不同的根.
::::

```{admonition} 注 3
:class: dropdown reading-note chapter-remark
:name: c07-remark-03

- 每个不同的根都贡献一个不同的一次因子，这些因子两两互素；它们的乘积整除 $f$，故根的个数不超过 $\deg f$。
```
:::::

:::::{container} statement-box exercise
:name: c07-statement-007

::::{container} source-line source-label
:name: p051-l07

练习 7.1
::::

::::{container} source-line
:name: p051-l08

给定 $f \in {\mathbb{F}}[ x], \deg(f) = 2$ 或 $3.$ 我们有 $f$ 是不可约多项式当且仅当 $f$ 在 $\mathbb{F}$ 中没有根.
::::

```{admonition} 注 4
:class: dropdown reading-note chapter-remark
:name: c07-remark-06

- 二次或三次多项式若可约，分解中必有一次因子，所以必有根。次数更高时，可约多项式未必有基域中的根。
```

## 形式导数与重根

:::::{container} statement-box definition
:name: c07-statement-005

::::{container} source-line source-label
:name: p051-l01

定义 7.3
::::

::::{container} source-line
:name: p051-l02

给定 $f = a_{0} + a_{1}x + \cdots + a_{n}x^{n}.$ 其形式导数为
::::

::::{container} source-line
:name: p051-l03

$$f' = a_{1} + 2a_{2}x + \cdots + na_{n}x^{n - 1}.$$
::::

```{admonition} 注 5
:class: dropdown reading-note chapter-remark
:name: c07-remark-04

- 这是形式导数，系数 $i$ 在系数域中解释。在正特征下，非恒定多项式也可能导数为零，例如特征 $p$ 时 $(x^p)'=0$。
```
:::::

:::::{container} statement-box exercise
:name: c07-statement-006

::::{container} source-line
:name: p051-l04

设 $f\ne0$。元素 $b \in {\mathbb{F}}$ 是多项式 $f$ 的一个重根当且仅当
::::

::::{container} source-line
:name: p051-l05

$$f(b) = f'(b) = 0.$$
::::

::::{container} source-line source-label
:name: p051-l06

练习 7.2
::::

```{admonition} 注 6
:class: dropdown reading-note chapter-remark
:name: c07-remark-05

- 由 $f=(x-b)g$ 得 $f'=g+(x-b)g'$，故 $f'(b)=g(b)$。于是 $f(b)=f'(b)=0$ 等价于 $(x-b)^2\mid f$。
```

## Lagrange 插值

:::::{container} statement-box theorem
:name: c07-statement-008

::::{container} source-line source-label
:name: p052-l01

定理 7.3
::::

::::{container} source-line
:name: p052-l02

（Lagrange插值公式）令 $n \geq 0.$ 给定 $n + 1$ 个 $\mathbb{F}$ 中不同的元素 $a_{0},a_{1},\cdots,a_{n}$, 以及 $\mathbb{F}$ 中任意 $n + 1$ 个元素 $b_{0},b_{1},\cdots,b_{n}.$ 我们可以找到唯一的次数不高于 $n$ 的多项式 $f \in {\mathbb{F}}[ x],$ 满足 $f(a_{i}) = b_{i}, 0 \leq i \leq n.$
::::

```{admonition} 注 7
:class: dropdown reading-note chapter-remark
:name: c07-remark-07

- 可显式取

  $$f(x)=\sum_{i=0}^n b_i\prod_{\substack{0\leq j\leq n\\j\ne i}}\frac{x-a_j}{a_i-a_j}.$$

  各分母非零。若两个次数不超过 $n$ 的多项式满足同样的插值条件，它们的差有 $n+1$ 个不同根，只能为零。
```

## 练习与解答

写出通过 $\mathbb F_7$ 中 $(0,1),(1,4),(2,2)$ 的次数至多为 $2$ 的插值多项式。

```{admonition} 参考解答
:class: dropdown tip

答案为 $x^2+2x+1$。代入三点得到 $1,4,2$；节点互异且次数上界为 $2$，故唯一。
```
