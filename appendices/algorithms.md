# 有限域计算的 Python 实现

本附录实现二元扩域的加法、乘法、幂、逆元、元素阶与迹。它将第 16 章的表示方法落实为可运行代码，并为计算实验提供公共模块。

## 多项式与位串

给定 $\mathbb F_2$ 上的 $m$ 次不可约多项式 $f$，在 $\mathbb F_2[x]/(f)$ 中，每个元素有唯一的次数小于 $m$ 的多项式代表元。用整数的第 $i$ 位记录 $x^i$ 的系数。例如 $x^4+x+1$ 的编码是 `0b10011`，元素 $x+1$ 的编码是 `0b0011`。

模多项式的编码必须包含首项。加法是 XOR；乘法先计算无进位乘积，再通过 XOR 约化最高次项。这些整数是位串编码，不能直接使用普通整数乘法实现域乘法。

## 运算流程

| 运算 | 实现方法 | 需要注意的条件 |
|---|---|---|
| 多项式余式 | 对齐最高次项后进行 XOR 消元 | 除式不能为零 |
| 加法 | 对编码逐位 XOR | 两个元素属于同一模型 |
| 乘法 | 移位累加，出现 $x^m$ 项时约化 | 模多项式须不可约 |
| 幂 | 平方乘算法 | 负指数需要先求逆 |
| 逆元 | $a^{-1}=a^{2^m-2}$ | $a\ne0$ |
| 元素阶 | 从 $1$ 逐次乘以该元素 | 只对非零元素定义 |
| 绝对迹 | 累加 Frobenius 共轭 | 结果属于 $\mathbb F_2$ |

不可约性检测采用试除次数不超过一半的首一因子，适合小次数教学实验。该实现重在清楚展示算法，不针对大规模计算优化。

## 一个完整算例

取 $f=x^4+x+1$，定义元 $\alpha=x+(f)$ 是本原元。可以建立长度为 $15$ 的指数表，令 $\operatorname{exp}(k)=\alpha^k$；其逆映射为非零元素的对数表。编码 $3$、$7$、$13$、$10$ 的对数分别为 $4$、$10$、$13$、$9$，因此

$$
\operatorname{log}(ab)=\operatorname{log}(a)+\operatorname{log}(b)\pmod{15},
\qquad
\operatorname{log}(a/b)=\operatorname{log}(a)-\operatorname{log}(b)\pmod{15}.
$$

以下程序计算编码 $3$ 与 $7$ 的乘积，以及编码 $13$ 与 $10$ 的商：

```python
from finitefield import GF2m

F = GF2m(0b10011)
print(F.mul(3, 7))    # 9
print(F.div(13, 10))  # 3
```

所得整数仍是域元素的编码。对数只对非零元素定义；使用查表法时，必须单独处理乘法中的零与除零。
