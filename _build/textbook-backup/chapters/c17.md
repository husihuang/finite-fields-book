::::{container} source-line source-label

定理
::::

::::{container} source-line
:name: p118-l02

（Hilbert 零点定理）给定域 $\mathbb F$ 及多项式 $f=f(x_1,\ldots,x_n)$。令 $S_1,\ldots,S_n$ 为 $\mathbb F$ 中的非空有限集合。如果
::::

::::{container} source-line
:name: p118-l03

$$f( s_{1},s_{2},\cdots,s_{n} ) = 0,\forall( s_{1},\cdots,s_{n} ) \in S_{1} \times \cdots \times S_{n},$$
::::

::::{container} source-line
:name: p118-l04

那么存在多项式 $h_{1},h_{2},\cdots,h_{n} \in {\mathbb{F}}[ x_{1},x_{2},\cdots,x_{n}]$ 使得 $f = \sum_{i = 1}^{n}{h_{i}g_{i}}, $其中$g_{i}(x_{i}) = \prod_{s \in S_{i}}^{}{(x_{i} - s)}$ $,\deg( h_{i} ) \leq \deg(f) - \deg( g_{i} ).$
::::

```{admonition} 备注 2
:class: dropdown reading-note chapter-remark
:name: c17-remark-02

- $g_i$ 在 $S_i$ 的全部元素处为零。逐变量带余除法将 $f$ 约化为逐变量次数均低于 $|S_i|$ 的余式；前一引理迫使该余式为零。
```

定理
::::

::::{container} source-line
:name: p119-l02

（组合零点定理）给定域 ${\mathbb{F}} $及其上 $n$ 个变量的多项式 $f = f(x_{1},x_{2},\cdots,x_{n}).$假设 $f$ 的次数 $\deg(f) = \sum_{i = 1}^{n}t_{i},t_{i} \geq 0,$ 并且单项式 $\prod_{i = 1}^{n}x_{i}^{t_{i}}$ 在 $f$ 中的系数不为 $0$. 如果 $S_{1},\cdots,S_{n}$ 是 $\mathbb{F}$ 中满足 ${|S}_{i}| > t_{i}$ 的子集, 那么可以找到 ${s_{1} \in S}_{1},{s_{2} \in S}_{2,}\cdots,s_{n}{\in S}_{n},$ 使得 $f(s_{1},s_{2},\cdots,s_{n}) \neq 0$.
::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c17-remark-03

- 总次数是所有非零单项式指数和的最大值。关键单项式位于最高总次数层，并且其系数非零；这些条件共同排除在整个网格上恒为零的可能。
```

## 推理练习（新增）

为何有限网格上的非零函数都有次数受限的唯一插值代表？

```{admonition} 展开解答（新增）
:class: dropdown tip

各变量分别使用 Lagrange 基多项式，再取它们的乘积即可插值。代表在 xᵢ 上的次数小于 |Sᵢ|；两个代表之差在整个网格为零，逐变量根数界迫使差为零。
```
