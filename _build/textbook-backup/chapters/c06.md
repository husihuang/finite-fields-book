# 不可约多项式

<span class="lecture-meta">原讲义第 45–48 页 · 正文与备注分别标明</span>

```{admonition} 补充判别：不可约与本原（新增）
:class: definition

不可约保证商为域，本原则进一步要求根的乘法阶最大。它们不同：$x^2+1$ 在 $\mathbb F_3$ 上不可约，但根的阶为 $4$，小于 $9-1=8$。
```

:name: p046-l01

定理
::::

::::{container} source-line
:name: p046-l02

给定 $f \in {\mathbb{F}}[ x].$ 剩余类环 ${\mathbb{F}}[ x]/(f)$ 构成一个域当且仅当 $f$ 在 $\mathbb{F}$ 上不可约.
::::

```{admonition} 备注 2
:class: dropdown reading-note chapter-remark
:name: c06-remark-02

- 若 $f$ 不可约，任一非零剩余类的代表元都与 $f$ 互素，Bézout 等式给出其逆元。反之，若 $f$ 有两个正次数真因子，它们的剩余类构成零因子。
```

推论
::::

::::{container} source-line

给定不可约多项式 $p \in {\mathbb{F}}[ x].$ 若 $p|f_{1}f_{2}\cdots f_{m}, $


（域上多项式唯一分解定理）给定非常数多项式 $f \in {\mathbb{F}}[ x].$ 我们有以下分解式：
::::

::::{container} source-line
:name: p048-l03

$$                    f = ap_{1}^{e_{1}}\cdots p_{k}^{e_{k}}                          ( \ast )    $$
::::

::::{container} source-line
:name: p048-l04

其中 $a \in {\mathbb{F}}, e_{i} \in {\mathbb{Z}}_{> 0}, 1 \leq i \leq k,  p_{1},\cdots,p_{k}$ 为 ${\mathbb{F}}[ x]$ 中不同的首1不可约多项式，并且分解式 $( \ast )$ 在不计次序的意义下是唯一的.
::::

```{admonition} 备注 4
:class: dropdown reading-note chapter-remark
:name: c06-remark-04

- 将各不可约因子规定为首一，非零常数因子就统一收集到 $a$ 中；唯一性允许调换各因子的排列顺序。
```

## 推理练习（新增）

证明 x⁴+x+1 在 F₂ 上不可约。

```{admonition} 展开解答（新增）
:class: dropdown tip

它在 0、1 处均不为零，故无一次因子。F₂ 上唯一首 1 二次不可约式为 x²+x+1，而上一节计算余式为 1。四次可约式必有一次或二次因子，故不可约。
```
