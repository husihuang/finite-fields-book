# 有限域的存在与子域

<span class="lecture-meta">原讲义第 68–74 页 · 正文与备注分别标明</span>

```{admonition} 补充解释：唯一性（新增）
:class: definition

有限域的唯一性指同构意义上的唯一。固定代数闭包后，每个 $p^m$ 元子域才是具体唯一的根集 $\{a:a^{p^m}=a\}$。其中子域交满足 $\mathbb F_{p^a}\cap\mathbb F_{p^b}=\mathbb F_{p^{\gcd(a,b)}}$。
```

令 $\mathbb{F}$ 为大小为 $q$ 的有限域. 那么

::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c10-remark-03

- 对非零元素应用乘法群的拉格朗日定理，得到 $a^{q-1}=1$；零元素也满足 $a^q=a$。
```

:::::{container} statement-box lemma
:name: c10-statement-004

::::{container} source-line source-label
:name: p070-l04

引理
::::

::::{container} source-line
:name: p070-l05

令 $\mathbb{F}$ 为大小为 $q$ 的有限域，且 $K$ 为 $\mathbb{F}$ 的子域. 则$K[ x]$中多项式 $x^{q} - x$ 在 ${\mathbb{F}}[ x]$ 中有如下分解:
::::

::::{container} source-line

```{admonition} 备注 4
:class: dropdown reading-note chapter-remark
:name: c10-remark-04

- $x^q-x$ 的导数为 $-1$，故没有重根。域中的 $q$ 个元素已经给出全部根。
```

定理

::::{container} source-line

（有限域的存在＆唯一性）对于任一素数 $p$ 和正整数 $n$，存在一个大小为 $p^{n}$ 的有限域. 并且任一大小为 $q = p^{n}$ 的有限域都和 $x^{q} - x$ 在 ${\mathbb{F}}_{p}$ 上的分裂域同构.

```{admonition} 备注 6
:class: dropdown reading-note chapter-remark
:name: c10-remark-06

```

（子域判别法则）令 ${\mathbb{F}}_{q}$ 为大小为 $q = p^{n}$ 的有限域.那么 ${\mathbb{F}}_{q}$ 的任一子域的大小为 $p^{m}$ ，其中 $m| n  $. 反之，若 $m| n   $则存在唯一的 大小为 $p^{m}$的${\mathbb{F}}_{q}$的子域.

```{admonition} 备注 7
:name: c10-remark-07

```

```{admonition} 展开解答（新增）
:class: dropdown tip

交是 F_(2²)。交中元素同时由第 6 和第 10 次 Frobenius 固定，因而由第 gcd(6,10)=2 次迭代固定；也可使用子域次数的整除判别。
```
