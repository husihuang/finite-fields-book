定义

以下设 $f$ 为非零多项式。

设 $f(b) = 0$. 若 ${(x - b)}^{k}|f(x)$, 但 ${(x - b)}^{k + 1} \nmid f(x),$ 我们称 $k$ 是根 $b$ 的重数，特别地


::::{container} source-line source-label
:name: p050-l01

定理
::::

::::{container} source-line
:name: p050-l02

以下记 $n=\deg f$。

（度数紧箍咒）给定 $f \in {\mathbb{F}}[ x], \deg(f) > 0.$ 如果 $b_{1},b_{2},\cdots,b_{m}$ 是 $f$ 在 $\mathbb{F}$ 中的 $m$ 个不同的根, 其对应的重数分别为 $k_{1},k_{2},\cdots,k_{m}$, 那么
::::

::::{container} source-line
:name: p050-l03

$$
(x-b_1)^{k_1}(x-b_2)^{k_2}\cdots(x-b_m)^{k_m}\mid f.
$$
::::

::::{container} source-line
:name: p050-l04

特别地$, k_{1} + k_{2} + \cdots + k_{m} \leq n,$ 从而 $f$ 在 $\mathbb{F}$ 中至多有 $n$ 个不同的根.
::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c07-remark-03

- 每个不同的根都贡献一个不同的一次因子，这些因子两两互素；它们的乘积整除 $f$，故根的个数不超过 $\deg f$。
```

元素 $b \in {\mathbb{F}}$ 是多项式 $f$ 的一个重根当且仅当

::::

::::{container} source-line source-label

练习
::::

```{admonition} 备注 5
:class: dropdown reading-note chapter-remark
:name: c07-remark-05

- 由 $f=(x-b)g$ 得 $f'=g+(x-b)g'$，故 $f'(b)=g(b)$。于是 $f(b)=f'(b)=0$ 等价于 $(x-b)^2\mid f$。
```

练习
::::

::::{container} source-line
:name: p051-l08

```{admonition} 备注 6
:class: dropdown reading-note chapter-remark
:name: c07-remark-06

- 二次或三次多项式若可约，分解中必有一次因子，所以必有根。次数更高时，可约多项式未必有基域中的根。
```

:name: c07-statement-008

::::{container} source-line source-label
:name: p052-l01

定理
::::

::::{container} source-line
:name: p052-l02

（Lagrange插值公式）令 $n \geq 0.$ 给定 $n + 1$ 个 $\mathbb{F}$ 中不同的元素 $a_{0},a_{1},\cdots,a_{n}$, 以及 $\mathbb{F}$ 中任意 $n + 1$ 个元素 $b_{0},b_{1},\cdots,b_{n}.$ 我们可以找到唯一的次数不高于 $n$ 的多项式 $f \in {\mathbb{F}}[ x],$ 满足 $f(a_{i}) = b_{i}, 0 \leq i \leq n.$
::::

```{admonition} 备注 7
:class: dropdown reading-note chapter-remark
:name: c07-remark-07

- 可显式取

  $$f(x)=\sum_{i=0}^n b_i\prod_{\substack{0\leq j\leq n\\j\ne i}}\frac{x-a_j}{a_i-a_j}.$$

  各分母非零。若两个次数不超过 $n$ 的多项式满足同样的插值条件，它们的差有 $n+1$ 个不同根，只能为零。
```
