## 阅读方法

1. 先阅读章首学习目标，再沿概念标题理解定义、定理、证明和例子。
2. 点击原文段落，通过 ↑ / ↓ 或“下一段”逐段阅读，展开本段说明。
3. 每节通过原页入口与 PPT 对照；原页对照和逐页笔记集中在各章末尾。
4. 使用各章对应的参数实验、自测和浏览器计算器核验理解。下载附录 Notebook 可修改并执行 Python 代码。

## 学习路径

群的运算与阶 → 环和理想 → 多项式与商域 → 域扩张 → 有限域结构 → 共轭、迹、范数与基 → 割圆多项式 → 表示与实现 → 组合应用。
