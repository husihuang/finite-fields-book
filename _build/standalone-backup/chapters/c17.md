引理

## 网格消失理想与带余除法

原页对照：[第 118 页](#slide-118)。

:::::{container} statement-box theorem
:name: c17-statement-002

::::{container} source-line source-label
:name: p118-l01

定理
::::

::::{container} source-line
:name: p118-l02

（有限网格上的消失理想定理）给定域 $\mathbb F$ 及多项式 $f=f(x_1,\ldots,x_n)$。令 $S_1,\ldots,S_n$ 为 $\mathbb F$ 中的非空有限集合。如果
::::

::::{container} source-line
:name: p118-l03

$$f( s_{1},s_{2},\cdots,s_{n} ) = 0,\forall( s_{1},\cdots,s_{n} ) \in S_{1} \times \cdots \times S_{n},$$
::::

::::{container} source-line
:name: p118-l04

那么存在多项式 $h_{1},h_{2},\cdots,h_{n} \in {\mathbb{F}}[ x_{1},x_{2},\cdots,x_{n}]$ 使得 $f = \sum_{i = 1}^{n}{h_{i}g_{i}}, $其中$g_{i}(x_{i}) = \prod_{s \in S_{i}}^{}{(x_{i} - s)}$ $,\deg( h_{i} ) \leq \deg(f) - \deg( g_{i} ).$
::::

```{admonition} 备注 2
:class: dropdown reading-note chapter-remark
:name: c17-remark-02

- $g_i$ 在 $S_i$ 的全部元素处为零。逐变量带余除法将 $f$ 约化为逐变量次数均低于 $|S_i|$ 的余式；前一引理迫使该余式为零。
```
:::::


## 组合零点定理的系数判别

原页对照：[第 119 页](#slide-119)。

:::::{container} statement-box theorem
:name: c17-statement-003

::::{container} source-line source-label
:name: p119-l01

定理
::::

::::{container} source-line
:name: p119-l02

（组合零点定理）给定域 ${\mathbb{F}} $及其上 $n$ 个变量的多项式 $f = f(x_{1},x_{2},\cdots,x_{n}).$假设 $f$ 的次数 $\deg(f) = \sum_{i = 1}^{n}t_{i},t_{i} \geq 0,$ 并且单项式 $\prod_{i = 1}^{n}x_{i}^{t_{i}}$ 在 $f$ 中的系数不为 $0$. 如果 $S_{1},\cdots,S_{n}$ 是 $\mathbb{F}$ 中满足 ${|S}_{i}| > t_{i}$ 的子集, 那么可以找到  $s_1\in S_1,\ldots,s_n\in S_n$，$ 使得 $f(s_{1},s_{2},\cdots,s_{n}) \neq 0$.
::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c17-remark-03

- 总次数是所有非零单项式指数和的最大值。关键单项式位于最高总次数层，并且其系数非零；这些条件共同排除在整个网格上恒为零的可能。
```

```{admonition} 证明（新增）
:class: dropdown tip

若 $S_i$ 无限，先从中选取 $t_i+1$ 个元素，故只需证明有限情形。反设 $f$ 在整个网格为零，由上一节定理写成 $f=\sum_i h_ig_i$，且 $\deg(h_ig_i)\leq\deg f$。由于 $g_i$ 的首项是 $x_i^{|S_i|}$，其余各项次数更低，最高总次数层只能来自 $h_i$ 与该首项的乘积。这些单项式的 $x_i$ 指数至少为 $|S_i|>t_i$，不可能产生 $\prod_i x_i^{t_i}$，与其系数非零矛盾。
```

## 推理练习（新增）

证明有限非空网格上的任意函数都有逐变量次数受限的唯一插值代表。

```{admonition} 展开解答（新增）
:class: dropdown tip

对每个变量分别取 Lagrange 基多项式，再将它们相乘并按函数值加权，即得插值多项式，满足 $\deg_{x_i}f<|S_i|$。两个代表之差在网格上恒零，逐变量根数引理迫使差为零，故代表唯一。
```
