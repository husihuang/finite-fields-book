## Schwartz–Zippel 零点数上界

原页对照：[第 123 页](#slide-123)。

:::::{container} statement-box lemma
:name: c19-statement-001

::::{container} source-line source-label
:name: p123-l01

引理
::::

::::{container} source-line
:name: p123-l02

（Schwartz–Zippel）给定域 $\mathbb F$ 以及总次数不超过 $d$ 的非零多项式 $f(x_1,\ldots,x_n)$。令 $S$ 为 $\mathbb F$ 的非空有限子集，则 $f$ 在 $S^n$ 中最多有 $d|S|^{n-1}$ 个零点。
::::

```{admonition} 备注 1
:class: dropdown reading-note chapter-remark
:name: c19-remark-01

- 该上界使用总次数 $d$，不是逐变量次数的乘积。除以 $|S|^n$ 后可得下一页的概率上界。
```

```{admonition} 证明（新增）
:class: dropdown tip

对变量数归纳。一元情形就是根数界。写 $f=\sum_{j=0}^k f_j(x_1,\ldots,x_{n-1})x_n^j$，其中 $f_k\ne0$，且 $\deg f_k\leq d-k$。若 $d\geq|S|$，所需上界已不小于总点数，结论直接成立。否则，由归纳，$f_k$ 为零的前 $n-1$ 个坐标至多有 $(d-k)|S|^{n-2}$ 组；每组至多贡献 $|S|$ 个零点。其余各组上一元多项式非零，至多有 $k$ 个根。合并得到零点数不超过 $d|S|^{n-1}$。
```

## 随机检验的错误概率

原页对照：[第 124 页](#slide-124)。

:::::{container} statement-box lemma
:name: c19-statement-003

::::{container} source-line source-label
:name: p124-l01

引理
::::

::::{container} source-line
:name: p124-l02

（Schwartz–Zippel）给定域 $\mathbb F$ 以及总次数为 $d$ 的非零多项式 $f(x_1,\ldots,x_n)$。令 $S$ 为 $\mathbb F$ 的非空有限子集，独立且均匀地从 $S$ 中随机选取 $r_1,\ldots,r_n$，则

$$
\Pr\bigl[f(r_1,\ldots,r_n)=0\bigr]\leq\frac d{|S|}.
$$
::::

```{admonition} 备注 2
:class: dropdown reading-note chapter-remark
:name: c19-remark-03

- 独立且均匀的抽样使每个点的概率均为 $|S|^{-n}$。实际可用的界为 $\min\{1,d/|S|\}$；重复独立试验可降低非零多项式被误判为零的概率。
```

## 二元多线性多项式的非零点下界

原页对照：[第 123 页](#slide-123)。

:::::{container} statement-box exercise
:name: c19-statement-002

::::{container} source-line source-label
:name: p123-l03

习题
::::

::::{container} source-line
:name: p123-l04

证明：若 $f\in\mathbb F_2[x_1,\ldots,x_n]$ 是总次数不超过 $d$ 的非零多线性多项式，且 $0\leq d\leq n$，则 $f$ 在 $\mathbb F_2^n$ 中至少有 $2^{n-d}$ 个非零点。
::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c19-remark-02

- 多线性条件是必要的：$x_1^2-x_1$ 在二元立方体上处处为零，虽是非零形式多项式，却不满足结论。多线性表示要求每个变量的次数至多为 $1$。
```

## 推理练习（新增）

证明非零多线性 $f\in\mathbb F_2[x_1,\ldots,x_n]$、$\deg f\leq d\leq n$ 至少有 $2^{n-d}$ 个非零取值点。

```{admonition} 展开解答（新增）
:class: dropdown tip

对 $n$ 归纳，写 $f=g+x_nh$。若 $h=0$，两层取值相同；$d\leq n-1$ 时由归纳得至少 $2\cdot2^{n-1-d}$ 个非零点，$d=n$ 时逐变量根数引理保证非零多线性多项式不可能在整个立方体恒零。若 $h\ne0$，则 $\deg h\leq d-1$，归纳给出至少 $2^{n-d}$ 个 $h$ 非零的输入，每个输入的 $g,g+h$ 恰有一个非零，所以仍有至少 $2^{n-d}$ 个非零点。零变量情形作为归纳起点。
```
