## 单位根与割圆域

原页对照：[第 98 页](#slide-098)、[第 99 页](#slide-099)。

:::::{container} statement-box definition
:name: c15-statement-001

```{raw} html
<span id="p098-l01"></span>
```

::::{container} source-line source-label
:name: p098-l02

定义
::::

::::{container} source-line
:name: p098-l03

设 $n$ 为正整数。多项式 $x^n-1$ 在域 $K$ 上的分裂域称为 $K$ 上的 $n$ 次割圆域，记为 $K^{(n)}$。多项式 $x^n-1$ 在 $K^{(n)}$ 中的根称为 $K$ 上的 $n$ 次单位根，所有这些根的集合记为 $E^{(n)}$。
::::

```{admonition} 备注 1
:class: dropdown reading-note chapter-remark
:name: c15-remark-01

- 单位根满足 $x^n=1$；本原单位根还要求乘法阶恰为 $n$。正特征下若特征整除 $n$，不同根的个数可能小于多项式次数。
```
:::::


:::::{container} statement-box theorem
:name: c15-statement-002

::::{container} source-line source-label
:name: p099-l01

定理
::::

::::{container} source-line
:name: p099-l02

设$ n$ 为正整数，$K $为特征为 $p\geq0$ 的域.
::::

::::{container} source-line
:name: p099-l03

如果 $p=0$ 或 $p \nmid n$，那么$ n$ 次单位根集合$ E^{(n)} $在 $K^{(n)}$ 中关于乘法构成一个阶为$ n $的循环群.
::::

::::{container} source-line
:name: p099-l04

如果 $p>0$ 且 $p\mid n$，则写成 $n=mp^e$，其中 $\gcd(m,p)=1$。我们有 $K^{(n)}=K^{(m)}$、$E^{(n)}=E^{(m)}$。多项式 $x^n-1$ 在 $K^{(n)}$ 中的根是 $E^{(m)}$ 的 $m$ 个元素，每个根的重数为 $p^e$。
::::

::::{container} source-line source-label
:name: p099-l05

证明要点见本框备注。
::::

```{admonition} 备注 2
:class: dropdown reading-note chapter-remark
:name: c15-remark-02

- 写 $n=mp^e$、$p\nmid m$，则 $x^n-1=(x^m-1)^{p^e}$。后者的 $m$ 个不同根各有重数 $p^e$，所以分裂域与根集都不变。
```

## 本原单位根与割圆多项式

原页对照：[第 100 页](#slide-100)、[第 101 页](#slide-101)。

:::::{container} statement-box definition
:name: c15-statement-003

::::{container} source-line source-label
:name: p100-l01

定义
::::

::::{container} source-line
:name: p100-l02

设$ K $为特征为 $p\geq0$ 的域，$n$ 为正整数，且 $p=0$ 或 $p\nmid n$. 那么循环群 $E^{(n)}$ 的一个生成元称为 $K$ 上的一个 $\mathbf{n}$ 次本原单位根.
::::
:::::


:::::{container} statement-box corollary
:name: c15-statement-004

::::{container} source-line source-label
:name: p100-l03

推论
::::

::::{container} source-line
:name: p100-l04

在 $K^{(n)}$ 中恰好有 $\phi(n)$ 个不同的 $n$ 次本原单位根。如果 $\zeta$ 是一个 $n$ 次本原单位根，那么所有的 $n$ 次本原单位根是：
::::

::::{container} source-line
:name: p100-l05

$$\zeta^{s},1 \leq s \leq n,\gcd(s,n) = 1.$$
::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c15-remark-03

- 这里的本原单位根位于割圆扩域，未必位于基域 $K$。对 $K=\mathbb F_q$，全部 $n$ 次单位根属于 $K$ 当且仅当 $n\mid q-1$。
```
:::::


:::::{container} statement-box definition
:name: c15-statement-005

::::{container} source-line source-label
:name: p101-l01

定义
::::

::::{container} source-line
:name: p101-l02

多项式
::::

::::{container} source-line
:name: p101-l03

$$
Q_n(x)=\prod_{\substack{1\leq s\leq n\\\gcd(s,n)=1}}(x-\zeta^s).
$$
::::

::::{container} source-line
:name: p101-l04

称为 $K$ 上的 $\mathbf{n}$ 次割圆多项式.
::::

```{admonition} 备注 4
:class: dropdown reading-note chapter-remark
:name: c15-remark-04

- 割圆多项式的根恰是乘法阶为 $n$ 的单位根，故次数为 $\phi(n)$。它也常记为 $\Phi_n$；这里沿用原讲义的 $Q_n$。
```

## 乘积分解与素数幂公式

原页对照：[第 102 页](#slide-102)、[第 103 页](#slide-103)、[第 106 页](#slide-106)。

:::::{container} statement-box theorem
:name: c15-statement-006

::::{container} source-line source-label
:name: p102-l01

定理
::::

::::{container} source-line
:name: p102-l02

设$ K $为特征为 $p\geq0$ 的域，$n$ 是正整数，且 $p=0$ 或 $p\nmid n$. 我们有
::::

::::{container} source-line
:name: p102-l03

$x^{n} - 1 = \prod_{d|n}^{}{Q_{d}(x)}.$
::::

::::{container} source-line
:name: p102-l04

$Q_n(x)$ 的系数属于 $K$ 的素子域。如果 $K$ 的素子域为有理数域，那么这些系数属于 $\mathbb Z$。
::::

```{admonition} 备注 5
:class: dropdown reading-note chapter-remark
:name: c15-remark-05

- 按每个单位根的乘法阶 $d\mid n$ 对根分组，即得乘积分解。特征为 $p$ 时，割圆多项式也可由整数系数割圆多项式模 $p$ 约化得到。
```
:::::


:::::{container} statement-box example
:name: c15-statement-007

::::{container} source-line source-label
:name: p103-l01

例子
::::

::::{container} source-line
:name: p103-l02

设 $r$ 为素数且 $k$ 为正整数，并设 $K$ 的特征为 $0$ 或不等于 $r$。则
::::

::::{container} source-line
:name: p103-l03

$$
Q_{r^k}(x)=1+x^{r^{k-1}}+x^{2r^{k-1}}+\cdots+x^{(r-1)r^{k-1}}.
$$
::::

::::{container} source-line
:name: p103-l04

特别地
::::

::::{container} source-line
:name: p103-l05

$$
\begin{aligned}
Q_{r^k}(x)&=\frac{x^{r^k}-1}{Q_1(x)Q_r(x)\cdots Q_{r^{k-1}}(x)} \\
&=\frac{x^{r^k}-1}{x^{r^{k-1}}-1}.
\end{aligned}
$$
::::

::::{container} source-line
:name: p103-l06

当$ k = 1$ 时，有$Q_{r}(x) = 1 + x + x^{2} + \cdots + x^{r - 1}.$
::::

```{admonition} 备注 6
:class: dropdown reading-note chapter-remark
:name: c15-remark-06

- 公式来自等比数列求和，亦可写成 $Q_{r^k}(x)=\sum_{j=0}^{r-1}x^{jr^{k-1}}$。其中 $k\geq1$，每个指数都是 $j$ 与 $r^{k-1}$ 的乘积。
```
:::::


:::::{container} statement-box lemma
:name: c15-statement-010

::::{container} source-line source-label
:name: p106-l01

引理
::::

::::{container} source-line
:name: p106-l02

沿用前文条件，设 $K$ 的特征为 $0$，或特征为素数 $p$ 且 $p\nmid n$。如果 $d$ 是正整数 $n$ 的一个因子，且 $1\leq d<n$，那么 $Q_n(x)$ 整除 $\dfrac{x^n-1}{x^d-1}$。
::::

```{admonition} 备注 7
:class: dropdown reading-note chapter-remark
:name: c15-remark-09

- $Q_n$ 出现在 $x^n-1$ 的割圆分解中，却不出现在 $x^d-1$ 的分解中，因为 $n\nmid d$；因而它整除相应商式。
```
:::::


## 不同基域上的割圆扩张

原页对照：[第 104 页](#slide-104)、[第 105 页](#slide-105)。

:::::{container} statement-box theorem
:name: c15-statement-008

::::{container} source-line source-label
:name: p104-l01

定理
::::

::::{container} source-line
:name: p104-l02

割圆域 $K^{(n)}$ 是 $K$ 的一个单代数扩张。并且
::::

::::{container} source-line
:name: p104-l03

如果$ K = {\mathbb{Q}} $，则割圆多项式 $Q_{n}$ 在 $K$ 上不可约，且 $[ K^{(n)}:K ] = \phi(n)$.
::::

::::{container} source-line
:name: p104-l04

如果 $K=\mathbb F_q$ 且 $\gcd(q,n)=1$，当 $n>1$ 时令 $d$ 为满足 $q^d\equiv1\pmod n$ 的最小正整数；当 $n=1$ 时令 $d=1$。则 $Q_n$ 可分解为 $\phi(n)/d$ 个在 $K[x]$ 中不同的首一不可约多项式，它们的次数均为 $d$。$K^{(n)}$ 是任何一个这样的不可约因式在 $K$ 上的分裂域，且 $[K^{(n)}:K]=d$。
::::

```{admonition} 备注 8
:class: dropdown reading-note chapter-remark
:name: c15-remark-07

- 当 $n>1$ 时，$d=\operatorname{ord}_n(q)$ 是 $q$ 模 $n$ 的乘法阶。每个本原单位根的 Frobenius 轨道长度都为 $d$，故每个不可约因子次数相同；$n=1$ 时约定 $d=1$。
```
:::::


:::::{container} statement-box theorem
:name: c15-statement-009

::::{container} source-line source-label
:name: p105-l01

定理
::::

::::{container} source-line
:name: p105-l02

有限域${ {\mathbb{F}}}_{q}$ 是其任一子域上的 $(q - 1)$ 次割圆域.
::::

```{admonition} 备注 9
:class: dropdown reading-note chapter-remark
:name: c15-remark-08

- $\mathbb F_q^\ast$ 的全部元素都是 $(q-1)$ 次单位根。在任一子域上添加这些根，即得到整个 $\mathbb F_q$。
```

## 推理练习（新增）

分解 $\mathbb F_3$ 上的 $Q_8(x)$。

```{admonition} 展开解答（新增）
:class: dropdown tip

$Q_8=x^4+1=(x^2+x+2)(x^2+2x+2)$。两因子在 $\mathbb F_3$ 中均无根，故不可约。$\operatorname{ord}_8(3)=2$，与因子次数相符。
```
