## 坐标映射与对偶基

原页对照：[第 93 页](#slide-093)、[第 94 页](#slide-094)。

:::::{container} statement-box example
:name: c14-statement-001

```{raw} html
<span id="p093-l01"></span>
```

::::{container} source-line source-label
:name: p093-l02

例子
::::

::::{container} source-line
:name: p093-l03

如果 $(\alpha_{1},\cdots,\alpha_{m})$ 是 $F/K$ 的一组基，那么
::::

::::{container} source-line
:name: p093-l04

$$\forall\alpha \in F,\alpha = c_{1}(\alpha)\alpha_{1} + c_{2}(\alpha)\alpha_{2} + \cdots + c_{m}(\alpha)\alpha_{m}.$$
::::

::::{container} source-line
:name: p093-l05

容易验证坐标映射

$$
\begin{aligned}
c_j:F&\longrightarrow K, \\
\alpha&\longmapsto c_j(\alpha)
\end{aligned}
$$

是线性变换。因此存在 $\beta_j\in F$ 使得 $c_j(\alpha)=\operatorname{Tr}_{F/K}(\beta_j\alpha)$ 对所有 $\alpha\in F$ 成立。
::::

::::{container} source-line
:name: p093-l06

特别地
::::

::::{container} source-line
:name: p093-l07

$$
\operatorname{Tr}_{F/K}(\beta_j\alpha_i)=\begin{cases}0,&i\ne j,\\1,&i=j.\end{cases}\qquad\text{(*)}
$$
::::

::::{container} source-line
:name: p093-l08

可以验证 $(\beta_{1},\cdots,\beta_{m})$ 是 $F/K$ 的另一组基.
::::

```{admonition} 备注 1
:class: dropdown reading-note chapter-remark
:name: c14-remark-01

- 坐标映射 $c_j$ 是 $K$ 线性泛函，由迹配对可唯一写成 $c_j(\beta)=\operatorname{Tr}_{F/K}(\beta\alpha_j^\ast)$。代入各基向量就得到对偶条件。
```
:::::


:::::{container} statement-box definition
:name: c14-statement-002

::::{container} source-line source-label
:name: p094-l01

定义
::::

::::{container} source-line
:name: p094-l02

我们称满足$ ( \ast ) $式的两组基 $(\alpha_{1},\cdots,\alpha_{m})$ 和$ ( \beta_{1},\cdots,\beta_{m} ) $互为对偶基.
::::

```{admonition} 备注 2
:class: dropdown reading-note chapter-remark
:name: c14-remark-02

- 右端为 Kronecker 符号 $\delta_{ij}$：$i=j$ 时为 $1$，其余为 $0$。对偶基使任意 $\beta\in F$ 的第 $j$ 个坐标直接由 $\operatorname{Tr}_{F/K}(\beta\alpha_j^\ast)$ 求得。
```

## 正规基及其存在性

原页对照：[第 94 页](#slide-094)。

:::::{container} statement-box definition
:name: c14-statement-003

::::{container} source-line source-label
:name: p094-l03

定义
::::

::::{container} source-line
:name: p094-l04

令 $K=\mathbb F_q<F=\mathbb F_{q^m}$。$F/K$ 的一组形如 $\{\alpha,\alpha^q,\ldots,\alpha^{q^{m-1}}\}$ 的基称为 $F/K$ 的正规基。
::::

```{admonition} 备注 3
:class: dropdown reading-note chapter-remark
:name: c14-remark-03

- 正规基由一个元素及其 Frobenius 共轭组成。它首先必须是一组基；仅有 $m$ 个不同的共轭元还不足以保证线性无关。
```
:::::


:::::{container} statement-box theorem
:name: c14-statement-004

::::{container} source-line source-label
:name: p094-l05

定理
::::

::::{container} source-line
:name: p094-l06

对于一个有限域$ K$ 及其有限扩张$ F/K$，都存在$ F/K$ 的一组正规基.
::::
:::::


## 迹矩阵与判别式

原页对照：[第 95 页](#slide-095)、[第 96 页](#slide-096)。

:::::{container} statement-box definition
:name: c14-statement-005

::::{container} source-line source-label
:name: p095-l01

定义
::::

::::{container} source-line
:name: p095-l02

设$ F/K$ 的次数为 $m . $我们定义元素 $\alpha_{1},\cdots,\alpha_{m} \in F$ 的判别式为
::::

::::{container} source-line
:name: p095-l03

(p095-l04)=

$$
\Delta_{F/K}(\alpha_1,\ldots,\alpha_m)=\begin{vmatrix}\operatorname{Tr}_{F/K}(\alpha_1\alpha_1)&\cdots&\operatorname{Tr}_{F/K}(\alpha_1\alpha_m)\\\vdots&\ddots&\vdots\\\operatorname{Tr}_{F/K}(\alpha_m\alpha_1)&\cdots&\operatorname{Tr}_{F/K}(\alpha_m\alpha_m)\end{vmatrix}.
$$
::::

```{admonition} 备注 4
:class: dropdown reading-note chapter-remark
:name: c14-remark-04

- 这是迹配对在所给元素组上的 Gram 行列式。它同时使用两项元素的乘积与迹，不应把矩阵误读成各元素迹的外积。
```
:::::


:::::{container} statement-box theorem
:name: c14-statement-006

::::{container} source-line source-label
:name: p096-l01

定理
::::

::::{container} source-line
:name: p096-l02

设$ F/K$ 的次数为 $m \quad $且 $\alpha_{1},\cdots,\alpha_{m} \in F$. 那么${\{\alpha}_{1},\cdots,\alpha_{m}\}$ 是 $F $在 $K$ 上的一组基，当且仅当$\mathrm{\Delta}_{F/K}(\alpha_{1},\cdots,\alpha_{m}) \neq 0$.
::::

::::{container} source-line source-label
:name: p096-l03

证明要点见本框备注。
::::

```{admonition} 备注 5
:class: dropdown reading-note chapter-remark
:name: c14-remark-05

- 迹配对非退化，故在一组基上的矩阵可逆。若元素线性相关，对应矩阵也有相同的线性关系，从而行列式为零。
```
:::::


## Moore 行列式判据

原页对照：[第 97 页](#slide-097)。

:::::{container} statement-box corollary
:name: c14-statement-007

::::{container} source-line source-label
:name: p097-l01

推论
::::

::::{container} source-line
:name: p097-l02

设 $\alpha_{1},\cdots,\alpha_{m} \in {\mathbb{F}}_{q^{m}}$. 那么$ {\{\alpha}_{1},\cdots,\alpha_{m}\} $ 是 ${\mathbb{F}}_{q^{m}}/{\mathbb{F}}_{q}$ 的一组基，当且仅当
::::

::::{container} source-line
:name: p097-l03

$$
\det\begin{pmatrix}\alpha_1&\alpha_2&\cdots&\alpha_m\\\alpha_1^q&\alpha_2^q&\cdots&\alpha_m^q\\\vdots&\vdots&\ddots&\vdots\\\alpha_1^{q^{m-1}}&\alpha_2^{q^{m-1}}&\cdots&\alpha_m^{q^{m-1}}\end{pmatrix}\ne0
$$
::::

```{admonition} 备注 6
:class: dropdown reading-note chapter-remark
:name: c14-remark-06

- 该矩阵称为 Moore 矩阵。其行列式非零刻画相对于 $\mathbb F_q$ 的线性无关，而不是相对于整个扩域的线性无关。
```

```{admonition} 证明（新增）
:class: dropdown tip

令 $M=(\alpha_j^{q^i})_{0\leq i<m,\,1\leq j\leq m}$。迹矩阵的第 $(j,k)$ 项是 $\sum_i\alpha_j^{q^i}\alpha_k^{q^i}$，所以迹矩阵等于 $M^{\mathsf T}M$。其行列式为 $(\det M)^2$，在任何特征下非零当且仅当 $\det M\ne0$；再应用判别式判据即得结论。
```
:::::

## 推理练习（新增）

给出正规基存在性的一条线性代数证明路线。

```{admonition} 展开解答（新增）
:class: dropdown tip

令 $\sigma(z)=z^q$，把 $F$ 看作 $m$ 维 $K$ 向量空间。$\sigma^m=I$。若次数小于 $m$ 的非零多项式 $\sum c_iT^i$ 消去 $\sigma$，则非零线性化多项式 $\sum c_iz^{q^i}$ 在 $q^m$ 个点全部为零，但其次数至多 $q^{m-1}$，与根数界矛盾。故 $\sigma$ 的极小多项式次数为 $m$。使用线性代数中的循环向量定理（极小多项式次数等于空间维数时存在循环向量），可取 $\alpha$ 使 $\alpha,\sigma\alpha,\ldots,\sigma^{m-1}\alpha$ 为基，即正规基。
```
