# 不可约多项式的根

<span class="lecture-meta">原讲义第 77–80 页 · 原文与新增内容分别标明</span>

```{admonition} 补充定义：Frobenius 轨道（新增）
:class: definition

轨道是 $\alpha,\alpha^q,\alpha^{q^2},\ldots$ 中直到第一次重复前的不同元素。轨道长度为 $d$ 时，极小多项式为 $\prod_{i=0}^{d-1}(x-\alpha^{q^i})$，其系数在 $\mathbb F_q$ 中。
```

## 推理练习（新增）

为何 α,α^q,… 的轨道长度就是极小多项式次数？

```{admonition} 展开解答（新增）
:class: dropdown tip

轨道元素都是极小多项式的根。轨道根乘积多项式被 Frobenius 固定，系数落在 Fq，并以 α 为根。极小性与整除性给出次数相等。
```
