```{admonition} 补充定义：多线性代表（新增）
:class: definition

在二元立方体上，$x_i^2=x_i$ 作为函数成立。约去这些关系后，每个函数有唯一的多线性多项式代表。非零多线性次数 $\le d\le n$ 的函数具有至少 $2^{n-d}$ 个非零值，这也是二元 Reed–Muller 码距离论证。
```

## 原讲义第 124 页

```{admonition} 逐页解释（新增）
:class: reading-note

均匀且独立抽样使概率等于根数/|S|ⁿ，需 S 非空。界可写为 min(1,d/|S|)；当 |S|≤d 时可能不给信息。独立重复 k 次可把非零多项式被误判为零的概率降到该上界的 k 次幂。
```

## 推理练习（新增）

证明非零多线性 f:F₂ⁿ→F₂ 的次数≤d≤n 时至少有 2^(n−d) 个非零点。

```{admonition} 展开解答（新增）
:class: dropdown tip

按 n 归纳，写 f=g+xₙh。若 h=0，两层取值相同；当 d≤n−1 时由归纳得至少 2·2^((n−1)−d) 个非零点，而 d=n 时非零函数至少有一个非零点。若 h≠0，其次数≤d−1，归纳给出至少 2^((n−1)−(d−1)) 个 h 非零的输入；每个输入上 g 与 g+h 恰有一个非零，得到所需下界。
```
