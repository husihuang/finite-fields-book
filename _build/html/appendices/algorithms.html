有限域计算的 Python 实现#

本附录实现二元扩域的加法、乘法、幂、逆元、元素阶与迹。它将第 16 章的表示方法落实为可运行代码，并为计算实验提供公共模块。

多项式与位串#

给定 \(\mathbb F_2\) 上的 \(m\) 次不可约多项式 \(f\)，在 \(\mathbb F_2[x]/(f)\) 中，每个元素有唯一的次数小于 \(m\) 的多项式代表元。用整数的第 \(i\) 位记录 \(x^i\) 的系数。例如 \(x^4+x+1\) 的编码是 0b10011，元素 \(x+1\) 的编码是 0b0011。

模多项式的编码必须包含首项。加法是 XOR；乘法先计算无进位乘积，再通过 XOR 约化最高次项。这些整数是位串编码，不能直接使用普通整数乘法实现域乘法。

一个完整算例#

取 \(f=x^4+x+1\)，定义元 \(\alpha=x+(f)\) 是本原元。可以建立长度为 \(15\) 的指数表，令 \(\operatorname{exp}(k)=\alpha^k\)；其逆映射为非零元素的对数表。编码 \(3\)、\(7\)、\(13\)、\(10\) 的对数分别为 \(4\)、\(10\)、\(13\)、\(9\)，因此

\[ \operatorname{log}(ab)=\operatorname{log}(a)+\operatorname{log}(b)\pmod{15}, \qquad \operatorname{log}(a/b)=\operatorname{log}(a)-\operatorname{log}(b)\pmod{15}. \]

以下程序计算编码 \(3\) 与 \(7\) 的乘积，以及编码 \(13\) 与 \(10\) 的商：

from finitefield import GF2m

F = GF2m(0b10011)
print(F.mul(3, 7))    # 9
print(F.div(13, 10))  # 3

所得整数仍是域元素的编码。对数只对非零元素定义；使用查表法时，必须单独处理乘法中的零与除零。

完整实现#

  1"""GF(2^m) 的位编码运算。
  2bit i 是 x^i 的系数；modulus 包含首项，例如 x^4+x+1 = 0b10011。
  3只使用 Python 标准库；这是教学实现，不针对大规模计算做优化。
  4"""
  5def poly_rem(a, b):
  6    if b == 0:
  7        raise ZeroDivisionError('零多项式不能作为除式')
  8    while a and a.bit_length() >= b.bit_length():
  9        a ^= b << (a.bit_length() - b.bit_length())
 10    return a
 11
 12
 13def irreducible(f):
 14    m = f.bit_length() - 1
 15    if m < 1:
 16        return False
 17    # 可约 m 次多项式必有次数不超过 m//2 的首 1 因子。
 18    for d in range(1, m // 2 + 1):
 19        for g in range(1 << d, 1 << (d + 1)):
 20            if poly_rem(f, g) == 0:
 21                return False
 22    return True
 23
 24
 25class GF2m:
 26    def __init__(self, modulus):
 27        if not isinstance(modulus, int) or not irreducible(modulus):
 28            raise ValueError('modulus 必须是 F2 上的不可约多项式位编码')
 29        self.modulus = modulus
 30        self.m = modulus.bit_length() - 1
 31        self.q = 1 << self.m
 32
 33    def check(self, a):
 34        if not isinstance(a, int) or not 0 <= a < self.q:
 35            raise ValueError(f'元素编码应在 0 到 {self.q-1} 之间')
 36
 37    def add(self, a, b):
 38        self.check(a); self.check(b)
 39        return a ^ b
 40
 41    def mul(self, a, b):
 42        self.check(a); self.check(b)
 43        out = 0
 44        while b:
 45            if b & 1:
 46                out ^= a
 47            b >>= 1
 48            a <<= 1
 49            if a & self.q:
 50                a ^= self.modulus
 51        return out
 52
 53    def power(self, a, n):
 54        self.check(a)
 55        if not isinstance(n, int):
 56            raise ValueError('指数必须是整数')
 57        if n < 0:
 58            return self.power(self.inv(a), -n)
 59        out = 1
 60        while n:
 61            if n & 1:
 62                out = self.mul(out, a)
 63            a = self.mul(a, a)
 64            n >>= 1
 65        return out
 66
 67    def inv(self, a):
 68        self.check(a)
 69        if a == 0:
 70            raise ZeroDivisionError('0 没有乘法逆元')
 71        return self.power(a, self.q - 2)
 72
 73    def div(self, a, b):
 74        return self.mul(a, self.inv(b))
 75
 76    def order(self, a):
 77        self.check(a)
 78        if a == 0:
 79            raise ValueError('0 不属于乘法群')
 80        t = 1
 81        for k in range(1, self.q):
 82            t = self.mul(t, a)
 83            if t == 1:
 84                return k
 85        raise AssertionError('不可约模多项式应给出有限域')
 86
 87    def trace(self, a):
 88        self.check(a)
 89        out, t = 0, a
 90        for _ in range(self.m):
 91            out ^= t
 92            t = self.mul(t, t)
 93        return out
 94
 95    def norm(self, a):
 96        return self.power(a, self.q - 1)
 97
 98    def log_tables(self, generator=2):
 99        if self.order(generator) != self.q - 1:
100            raise ValueError('查表生成元必须是本原元')
101        exp, log, a = [], {}, 1
102        for k in range(self.q - 1):
103            exp.append(a); log[a] = k
104            a = self.mul(a, generator)
105        return exp, log
106
107    def mul_log(self, a, b, generator=2):
108        self.check(a); self.check(b)
109        if a == 0 or b == 0:
110            return 0
111        exp, log = self.log_tables(generator)
112        return exp[(log[a] + log[b]) % (self.q - 1)]
113
114    def div_log(self, a, b, generator=2):
115        self.check(a); self.check(b)
116        if b == 0:
117            raise ZeroDivisionError('不能除以零')
118        if a == 0:
119            return 0
120        exp, log = self.log_tables(generator)
121        return exp[(log[a] - log[b]) % (self.q - 1)]
