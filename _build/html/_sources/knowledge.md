# 知识图谱与学习状态

从全书结构进入某一章，再选择概念查看它的先修知识、推导关系和应用。箭头从提供知识的节点指向使用知识的节点；“定义与刻画”连接概念及其描述。关系表示本书中的学习联系，不意味着每条边都是逻辑上的充分必要条件。

例如，从有限域 $\mathbb F_q$ 的乘法群进入“本原元”，可以回顾循环群与元素的阶，再继续学习幂表示、指数表和对数表。节点中的公式与正文使用相同的数学记号。

学习状态由你自己填写。阅读过、初步理解和能够独立运用是不同的阶段；进度按标记过的核心概念统计，不根据停留时间或点击次数判断掌握程度。
