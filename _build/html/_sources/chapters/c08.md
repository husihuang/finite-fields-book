## 添加元素与生成子域

:::::{container} statement-box definition
:name: c08-statement-005

::::{container} source-line source-label
:name: p055-l01

定义 8.3
::::

::::{container} source-line
:name: p055-l02

给定域 $K < {\mathbb{F}}$ 以及 $M \subset {\mathbb{F}}.$ 我们定义域 $K(M)$ 为 $\mathbb{F}$ 中所有同时包含 $K$ 和 $M$ 的子域的交，并称之为由域 $K$ 添加 $M$ 中元素所得到的扩域.
::::

::::{container} source-line
:name: p055-l03

1\) 若 $M = \{ \theta_{1},\cdots,\theta_{n} \},$ 我们也记 $K(M) = K( \theta_{1},\cdots,\theta_{n} ).$
::::

::::{container} source-line
:name: p055-l04

2\) 若 $M = \{ \theta \},$ 则称 $L = K(\theta)$ 为域 $K$ 的单扩张，并称元素 $\theta$ 为 $L$ 在 $K$ 上的一个定义元.
::::

::::{container} source-line
:name: p055-l05

3\) 可以验证 $K(M)$ 是 $\mathbb{F}$ 中最小的同时包含 $K$ 和 $M$ 的子域.
::::

```{admonition} 注 3
:class: dropdown reading-note chapter-remark
:name: c08-remark-03

- $K(M)$ 的交集定义刻画了“最小的子域”。与只允许多项式表达式的 $K[M]$ 相比，$K(M)$ 还允许非零分母；代数单扩张中二者相等。
```

## 代数元与超越元

:::::{container} statement-box definition
:name: c08-statement-006

::::{container} source-line source-label
:name: p056-l01

定义 8.4
::::

::::{container} source-line
:name: p056-l02

给定域 $K < {\mathbb{F}}$ 以及 $\theta \in {\mathbb{F}}.$ 若 $\theta$ 满足代数方程
::::

::::{container} source-line
:name: p056-l03

$$
a_n\theta^n+a_{n-1}\theta^{n-1}+\cdots+a_1\theta+a_0=0,\qquad a_i\in K.
$$

其中各系数不全为 $0$。
::::

::::{container} source-line
:name: p056-l04

则称 $\theta$ 在 $K$ 上是代数的. 若不存在如上的代数方程，则称 $\theta$ 在 $K$ 上是超越的. 如果 $\mathbb{F}$ 中的每一个元素在 $K$上都是代数的，则称 $\mathbb{F}$ 是 $K$ 的代数扩张. 反之，若 $\mathbb{F}$ 中存在至少一个在 $K$ 上超越的元素，则称 $\mathbb{F}$ 是 $K$ 的超越扩张.
::::

```{admonition} 注 4
:class: dropdown reading-note chapter-remark
:name: c08-remark-04

- “在 $K$ 上”指定方程系数的来源，因而代数性与基域有关。有限扩张一定是代数扩张，但代数扩张未必具有有限次数。
```

## 代入同态与极小多项式

:::::{container} statement-box theorem
:name: c08-statement-007

::::{container} source-line source-label
:name: p057-l01

定理 8.2
::::

::::{container} source-line
:name: p057-l02

假定元素 $\theta \in {\mathbb{F}}$ 是 $K$ 上的代数元. 令
::::

::::{container} source-line
:name: p057-l03

$$J = \{ f \in K[ x]:f(\theta) = 0 \}.$$
::::

::::{container} source-line
:name: p057-l04

则存在唯一的首$1$多项式 $g \in K[ x]$ 使得 $J = (g).$ 并且多项式 $g$ 在 $K$ 上不可约.
::::

```{admonition} 注 5
:class: dropdown reading-note chapter-remark
:name: c08-remark-05

- 代入映射 $\operatorname{ev}_\theta:K[x]\to\mathbb F$，$f\mapsto f(\theta)$ 是环同态，且核为 $J$。代数性使 $J$ 非零；其首一生成元的不可约性来自域中无零因子及次数的最小性。
```

```{admonition} 证明
:class: dropdown tip

代入映射的核 $J$ 是非零理想，故由唯一首一多项式 $g$ 生成。若 $g=uv$ 且两因子次数均为正，则 $u(\theta)v(\theta)=0$。扩域是域，故某个因子在 $\theta$ 处为零；该因子属于 $J$，却比 $g$ 次数低，矛盾。因此 $g$ 不可约。
```

:::::{container} statement-box theorem
:name: c08-statement-009

::::{container} source-line source-label
:name: p058-l01

定理 8.3
::::

::::{container} source-line
:name: p058-l02

假定元素 $\theta \in {\mathbb{F}}$ 是域 $K$ 上的代数元. 我们有以下关于 $\theta$ 的极小多项式 $g$ 的性质:
::::

::::{container} source-line
:name: p058-l03

1\) $g$ 是 $K[ x]$ 中的不可约多项式.
::::

::::{container} source-line
:name: p058-l04

2\) 对于 $f \in K[ x],$ 有 $f(\theta) = 0$ 当且仅当 $g|f.$
::::

::::{container} source-line
:name: p058-l05

3\) $g$ 是 $K[ x]$ 中以 $\theta$ 为根的次数最低的首$1$多项式.
::::

```{admonition} 注 6
:class: dropdown reading-note chapter-remark
:name: c08-remark-06

- 任意使 $\theta$ 归零的多项式都属于代入同态的核，因而都被极小多项式整除。首一条件保证极小多项式的唯一性。
```

## 交互实验：由 Frobenius 轨道计算极小多项式

在二元有限域中，依次取平方得到 $a,a^2,a^4,\ldots$，直到回到起点。这称为 Frobenius 轨道。本实验预览轨道与极小多项式的联系，其一般证明将在第 12 章给出。

输入采用 $\alpha$ 的幂表示，零元素单独选择。本实验采用本原多项式模型；输出中的共轭与极小多项式使用域元素的代数表示，而非整数编码。

## 练习与解答

求满足 $\alpha^2=2$ 的元素 $\alpha$ 在 $\mathbb F_3$ 上的极小多项式。

```{admonition} 参考解答
:class: dropdown tip

$x^2+1$ 在 $\alpha$ 处为零，在 $\mathbb F_3$ 的 $0,1,2$ 处均非零，故不可约。它是首一多项式，因此就是极小多项式。
```
