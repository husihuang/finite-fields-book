## 和集与 Cauchy–Davenport 定理

:::::{container} statement-box theorem
:name: c18-statement-001

::::{container} source-line source-label
:name: p120-l01

定理 18.1
::::

::::{container} source-line
:name: p120-l02

(Cauchy-Davenport) 令 $p$ 为素数, 并且 $A, B$ 为 ${\mathbb{F}}_{p}$ 中两个非空子集. 我们有
::::

::::{container} source-line
:name: p120-l03

$$|A + B| \geq \min\{ p,|A| + |B| - 1\}.$$
::::

```{admonition} 注 1
:class: dropdown reading-note chapter-remark
:name: c18-remark-01

- 和集定义为 $A+B=\{a+b:a\in A,b\in B\}$，重复出现的和只计一次。若和集过小，可构造在 $A\times B$ 消失的多项式，再应用组合零点定理得到矛盾。
```

```{admonition} 证明
:class: dropdown tip

记 $a=|A|,b=|B|$。若 $a+b>p$，对任意 $c\in\mathbb F_p$，集合 $A$ 与 $c-B=\{c-y:y\in B\}$ 的大小之和超过 $p$，故两集合必相交。于是 $c=x+y$，其中 $x\in A,y\in B$，所以 $A+B=\mathbb F_p$。

下面设 $a+b\leq p$。反设 $|A+B|\leq a+b-2$。取 $C\supseteq A+B$ 且 $|C|=a+b-2$；由于 $a+b-2<p$，这样的 $C\subseteq\mathbb F_p$ 存在。构造

$$P(X,Y)=\prod_{c\in C}(X+Y-c).$$

对每个 $(x,y)\in A\times B$，都有 $x+y\in C$，故 $P(x,y)=0$。另一方面，$P$ 的总次数为 $a+b-2$；它的最高次齐次部分是 $(X+Y)^{a+b-2}$，从而

$$[X^{a-1}Y^{b-1}]P=\binom{a+b-2}{a-1}\ne0\quad\text{在 }\mathbb F_p\text{ 中}.$$

最后一步成立是因为 $0\leq a-1,b-1,a+b-2<p$，阶乘均不被 $p$ 整除。组合零点定理应用于 $S_1=A,S_2=B,t_1=a-1,t_2=b-1$，断言 $P$ 在 $A\times B$ 上有非零取值，矛盾。故 $|A+B|\geq a+b-1$。当 $a=b=1$ 时也包含在上述论证中（此时 $C=\varnothing$，空积为 $1$）。
```
:::::

```{admonition} 例：和集怎样增长
:class: example

在 $\mathbb F_7$ 中取 $A=\{0,1,2\}$、$B=\{0,1,2\}$，则 $A+B=\{0,1,2,3,4\}$，恰有 $3+3-1=5$ 个元素，说明下界可以取到。若把 $B$ 换成 $\{0,1,2,3,4\}$，则 $|A|+|B|=8>7$，每个剩余类都可写成 $a+b$，和集成为整个 $\mathbb F_7$。两个例子分别展示了定理中的 $|A|+|B|-1$ 和 $p$ 两种情形。

在第一个例子中若假设和集只有 $4$ 个元素，就要取 $|C|=4$，构造 $\prod_{c\in C}(X+Y-c)$。它的 $X^2Y^2$ 系数是 $\binom42=6\ne0$（模 $7$），因此不可能在 $A\times B$ 上恒为零。
```

## Chevalley–Warning 的零点计数

:::::{container} statement-box theorem
:name: c18-statement-002

::::{container} source-line source-label
:name: p121-l01

定理 18.2
::::

::::{container} source-line
:name: p121-l02

（Chevalley-Warning定理）令 $p$ 为素数. 给定环 ${\mathbb{F}}_{p}[ x_{1},\cdots,x_{n}]$ 中 $m$ 个多项式
::::

::::{container} source-line
:name: p121-l03

(p121-l04)=
(p121-l05)=

$$
\begin{aligned}
P_1&=P_1(x_1,x_2,\ldots,x_n), \\
&\vdots \\
P_m&=P_m(x_1,x_2,\ldots,x_n).
\end{aligned}
$$
::::

::::{container} source-line
:name: p121-l06

如果 $n>\sum_{i=1}^m\deg(P_i)$，则 $P_1,\ldots,P_m$ 的公共零点数是 $p$ 的倍数。
::::

::::{container} source-line source-label
:name: p121-l07

注记
::::

::::{container} source-line
:name: p121-l08

Artin于1934年提出猜想, Chevalley在1935年给出证明, 并由Warning在1935年推广.
::::

```{admonition} 注 2
:class: dropdown reading-note chapter-remark
:name: c18-remark-02

- 在 $\mathbb F_p$ 中对所有点求和，表达式 $\prod_i(1-P_i(x)^{p-1})$ 只在公共零点取 $1$。次数条件使总和为零，从而公共零点数被 $p$ 整除。方程组可能没有解；若已知零向量是一个公共零点，则公共零点至少有 $p$ 个，因而一定还有非零解。
```

```{admonition} 证明
:class: dropdown tip

先在 $\mathbb F_p$ 上证明。费马小定理给出：$u^{p-1}=0$（$u=0$）或 $1$（$u\ne0$）。因此

$$I(x_1,\ldots,x_n)=\prod_{i=1}^{m}\bigl(1-P_i(x_1,\ldots,x_n)^{p-1}\bigr)$$

在公共零点取 $1$，在其他点取 $0$。若公共零点数为 $N$，则作为 $\mathbb F_p$ 中的等式，

$$N=\sum_{x\in\mathbb F_p^n}I(x).$$

展开 $I$。任一出现的单项式 $c x_1^{e_1}\cdots x_n^{e_n}$ 满足

$$e_1+\cdots+e_n\leq(p-1)\sum_i\deg P_i<n(p-1).$$

所以至少有一个 $e_j<p-1$。对该单项式在整个 $\mathbb F_p^n$ 上求和，可按坐标分离为 $c\prod_j\sum_{u\in\mathbb F_p}u^{e_j}$，其中 $u^0=1$。当 $e_j=0$ 时，该因子为 $p=0$；当 $1\leq e_j<p-1$ 时，非零元素的幂和为 $0$（取 $\mathbb F_p^\times$ 的生成元并求等比级数）。因此每个单项式的总和都是 $0$，进而 $N=0$ 在 $\mathbb F_p$ 中成立，即整数 $N$ 被 $p$ 整除。

同样的论证适用于 $\mathbb F_q$：把 $p-1$ 换为 $q-1$，并用 $\sum_{u\in\mathbb F_q}1=q=0$。所得结论仍是**特征 $p$**整除公共零点数，而不是要求 $q$ 整除。
```

:name: c18-statement-003

::::{container} source-line
:name: p121-l10

证明若在任意有限域$\mathbb{F}$上考虑该问题，结论换成公共零点数目是域的特征的倍数
::::
:::::

```{admonition} 例：逐点计数与整除结论
:class: example

在 $\mathbb F_3^3$ 中考虑 $P(x,y,z)=x+y+z$。它的次数为 $1<3$。任取 $x,y\in\mathbb F_3$，恰有一个 $z=-x-y$ 使 $P=0$，所以公共零点（此处只有一个方程）的数目是 $3^2=9$，确实被 $3$ 整除。证明中的指示函数是 $1-(x+y+z)^2$：在这 $9$ 个零点上取 $1$，在其余 $18$ 个点上取 $0$。

整除不等于必有解。例如常数方程 $1=0$ 没有解，零点数 $0$ 仍被 $3$ 整除；但若方程组已知有零向量这个解，零点数就至少是 $3$，必另有非零解。
```

::::{container} source-line source-label

定义 18.1
::::

::::{container} source-line
:name: p122-l02

(零和问题) 给定正整数$n$，求最小的正整数$m$，使得任意$m$ 长的整数序列$a_1,\ldots,a_m$，都存在$n$长的子序列$a_{i_{1}},...,a_{i_{n}}$，使得其和被$n$整除。
::::

```{admonition} 注 3
:class: dropdown reading-note chapter-remark
:name: c18-remark-03

- 序列允许重复元素；子序列由不同下标选取。因而“选取 $n$ 项”与从互异元素组成的集合中选取 $n$ 个元素不同。
```

:name: c18-statement-005

```{raw} html
<div class="statement-title">命题 18.1</div>
```

::::{container} source-line source-label
:name: p122-l03

下界
::::

::::{container} source-line
:name: p122-l04

$$m \geq 2n - 1$$
::::

```{admonition} 注 4
:class: dropdown reading-note chapter-remark
:name: c18-remark-04

- 当 $n\geq2$ 时，取 $n-1$ 个 $0$ 和 $n-1$ 个 $1$。任意 $n$ 项的和均在 $1,\ldots,n-1$ 之间，不能被 $n$ 整除，从而长度 $2n-2$ 不足。
```
:::::

```{admonition} 下界的证明与例子
:class: tip

当 $n\geq2$ 时，取 $n-1$ 个 $0$ 和 $n-1$ 个 $1$，总长 $2n-2$。从中选 $n$ 项时，既不可能全选 $0$，也不可能全选 $1$；所选的 $1$ 的个数介于 $1$ 与 $n-1$ 之间，所以这 $n$ 项的和不被 $n$ 整除。因此所求的最小长度至少为 $2n-1$。例如 $n=3$ 时，序列 $(0,0,1,1)$ 中任取三项，和只能是 $1$ 或 $2$；长度再增加到 $5$，下文的定理保证一定能选出三项零和。
```

## Erdős–Ginzburg–Ziv 定理

定理 18.3

::::{container} source-line
:name: p122-l06

（Erdős–Ginzburg–Ziv） $m = 2n - 1$
::::
:::::

:::::{container} statement-box proposition
:name: c18-statement-007

::::{container} source-line source-label
:name: p122-l07

命题 18.2
::::

::::{container} source-line
:name: p122-l08

给定素数 $p.$ 任意一条 ${\mathbb{F}}_{p}$ 中长 $2p - 1$ 的序列都包含一条$p$长子序列且其元素之和为 $0$.
::::

```{admonition} 证明
:class: dropdown tip

记 $N=2p-1$。对给定的 $a_1,\ldots,a_N\in\mathbb F_p$，引入 $N$ 个变量，考虑方程组

$$\sum_{i=1}^{N}x_i^{p-1}=0,\qquad \sum_{i=1}^{N}a_i x_i^{p-1}=0.$$

两式的次数之和不超过 $2(p-1)<N$。由 Chevalley–Warning 定理，公共解的数目被 $p$ 整除。零向量是其中一个解，因此公共解不可能只有一个，必有非零解 $(x_i)$。

设 $T=\{i:x_i\ne0\}$。在 $\mathbb F_p$ 中，$x_i^{p-1}$ 对 $i\in T$ 等于 $1$，对其余下标等于 $0$。第一式于是变为 $|T|=0$（模 $p$）。由于 $1\leq |T|\leq2p-1$，只能有 $|T|=p$。第二式随即变为 $\sum_{i\in T}a_i=0$。这些互不相同的下标给出所需的 $p$ 项子序列。
```
:::::

```{admonition} 例：从非零解读出零和子序列
:class: example

在 $\mathbb F_3$ 中，序列 $(0,0,1,1,2)$ 有 $2\cdot3-1=5$ 项。取下标 $T=\{1,3,5\}$，相应的三项为 $0,1,2$，和为 $0$（模 $3$）。在命题证明的方程组中，取 $x_1=x_3=x_5=1$、其余 $x_i=0$，便得到一个非零公共解。变量 $x_i$ 的非零与否只负责标记**选取哪些下标**。
```

```{admonition} 定理 18.3 的完整证明：从素数走向任意正整数
:class: dropdown tip

命题 18.2 已证明素数 $p$ 的情形。再证明一个合成步骤：假设结论对正整数 $a,b$ 都成立，则对 $n=ab$ 也成立。给定 $2ab-1$ 项整数，反复从剩余项中选出互不相交的 $a$ 项组，使每组的和被 $a$ 整除。选取第 $j$ 组之前（$1\leq j\leq2b-1$），尚有

$$2ab-1-(j-1)a\geq2ab-1-(2b-2)a=2a-1$$

项，因此可从剩余项中取 $2a-1$ 项并应用 $a$ 的结论。这样得到 $2b-1$ 个互不相交的 $a$ 项组，其组和分别写为 $a u_1,\ldots,a u_{2b-1}$，其中 $u_i$ 是整数。对 $u_1,\ldots,u_{2b-1}$ 应用 $b$ 的结论，选出 $b$ 个使其和被 $b$ 整除。对应的 $b$ 个组共有 $ab$ 个不同下标，原序列中这些项的和为 $a$ 乘以 $b$ 的倍数，因而被 $ab$ 整除。

以 $n=1$ 为起点，结合素数情形和正整数的素因子分解，反复使用合成步骤即可证明任意 $n$ 的上界 $m\leq2n-1$。前面的下界给出 $m\geq2n-1$，所以 $m=2n-1$。
```

## 练习与解答

以 $n=6=2\cdot3$ 为例，说明如何从任意 $11$ 项整数中选出 $6$ 项，使其和被 $6$ 整除。指出要先取多少个互不相交的二项组，以及每个阶段至少剩余多少项。

```{admonition} 参考解答
:class: dropdown tip

先依次取 $2\cdot3-1=5$ 个互不相交的二项组，每组的和为偶数。选第五组之前，原来 $11$ 项中已经使用 $8$ 项，仍剩 $3=2\cdot2-1$ 项，所以仍能用 $n=2$ 的结论选出一组。将五个组和分别除以 $2$，得到五个整数；由 $n=3$ 的结论选出其中三个，使其和被 $3$ 整除。这三个组包含六个不同下标，原来六项之和等于 $2$ 乘以 $3$ 的倍数，故被 $6$ 整除。
```
