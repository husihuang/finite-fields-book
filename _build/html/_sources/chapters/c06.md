# 第 6 章 不可约多项式

不可约多项式是构造有限域的关键。学完本章应能解释不可约性与商域的等价关系，使用素元性质，并区分不可约与本原。

```{admonition} 学习目标
:class: tip chapter-goals

- 理解不可约性及其与根的关系。
- 理解不可约性与商环成为域的等价关系。
- 掌握多项式环的唯一因子分解。
```

```{admonition} 判别：不可约与本原
:class: definition

不可约保证商为域，本原则进一步要求根的乘法阶最大。它们不同：$x^2+1$ 在 $\mathbb F_3$ 上不可约，但根的阶为 $4$，小于 $9-1=8$。
```

## 不可约多项式与商域

:::::{container} statement-box theorem
:name: c06-statement-002

::::{container} source-line source-label
:name: p046-l01

定理 6.1
::::

::::{container} source-line
:name: p046-l02

给定 $f \in {\mathbb{F}}[ x].$ 剩余类环 ${\mathbb{F}}[ x]/(f)$ 构成一个域当且仅当 $f$ 在 $\mathbb{F}$ 上不可约.
::::

```{admonition} 注 2
:class: dropdown reading-note chapter-remark
:name: c06-remark-02

- 若 $f$ 不可约，任一非零剩余类的代表元都与 $f$ 互素，Bézout 等式给出其逆元。反之，若 $f$ 有两个正次数真因子，它们的剩余类构成零因子。
```

```{admonition} 证明
:class: dropdown tip

若 $f$ 不可约，对非零剩余类 $a+(f)$，有 $\gcd(a,f)=1$，故存在 $u,v$ 使 $ua+vf=1$，$u+(f)$ 即其逆元。反向分三类：$f=0$ 时商环为 $\mathbb F[x]$，其中 $x$ 不可逆；$f$ 为非零常数时商环为零环，不是域；$f$ 为非零非常数且可约时，两个正次数真因子的剩余类非零而乘积为零，也不是域。
```

## 素元性质与唯一分解

:::::{container} statement-box corollary
:name: c06-statement-003

::::{container} source-line source-label
:name: p047-l01

推论 6.1
::::

::::{container} source-line
:name: p047-l02

给定不可约多项式 $p \in {\mathbb{F}}[ x].$ 若 $p|f_{1}f_{2}\cdots f_{m}, $
::::

::::{container} source-line
:name: p047-l03

$f_{i} \in {\mathbb{F}}[ x].$ 则存在 $j, 1 \leq j \leq m,$ 使得 $p|f_{j}.$
::::

```{admonition} 注 3
:class: dropdown reading-note chapter-remark
:name: c06-remark-03

- 在域上的多项式环中，不可约多项式具有素元性质：若 $p\nmid f$，则 $\gcd(p,f)=1$，用 Bézout 等式即可推出 $p\mid g$。
```

练习 6.1
::::

::::{container} source-line
:name: p048-l02

（域上多项式唯一分解定理）给定非零非常数多项式 $f \in {\mathbb{F}}[ x].$ 我们有以下分解式：
::::

::::{container} source-line
:name: p048-l03

$$                    f = ap_{1}^{e_{1}}\cdots p_{k}^{e_{k}}                          ( \ast )    $$
::::

::::{container} source-line
:name: p048-l04

其中 $a \in \mathbb F^\ast, e_{i} \in {\mathbb{Z}}_{> 0}, 1 \leq i \leq k,  p_{1},\cdots,p_{k}$ 为 ${\mathbb{F}}[ x]$ 中不同的首1不可约多项式，并且分解式 $( \ast )$ 在不计次序的意义下是唯一的.
::::

```{admonition} 注 4
:class: dropdown reading-note chapter-remark
:name: c06-remark-04

- 将各不可约因子规定为首一，非零常数因子就统一收集到 $a$ 中；唯一性允许调换各因子的排列顺序。
```

## 练习与解答

证明 $x^4+x+1$ 在 $\mathbb F_2$ 上不可约。

```{admonition} 参考解答
:class: dropdown tip

它在 $0,1$ 处均非零，故无一次因子。唯一首一二次不可约多项式为 $x^2+x+1$，除它的余式为 $1$。四次可约多项式必有一次或二次因子，因此给定多项式不可约。
```
