# 有限域及其应用

本书从群、环与多项式出发，建立域扩张和有限域的基本理论，进而讨论共轭、迹、范数、基、割圆多项式，以及有限域的计算实现和组合应用。定义、定理、证明与计算实验相互配合，帮助读者把抽象结构与具体运算联系起来。

## 预备知识

读者应熟悉集合与映射、整数整除和素数、基础多项式运算，以及线性代数中的向量空间、基与维数。群、环、理想和域扩张的基本概念将在正文中介绍。未学过抽象代数的读者可从第一章顺序阅读；已有基础的读者可从域扩张部分开始，并按需回顾前面的定义。

## 怎样使用本书

每章先说明学习目标，再按概念展开定义、结论、证明和例子。建议先确认每个定理的条件，再尝试自行解释证明的关键步骤，最后使用练习与交互实验检查理解。

证明和参考解答可以展开阅读。标为**高阶选读**的内容适合在掌握前置知识后继续学习，初读时可先掌握其结论与证明思路。章末的学习检查用于回顾本章目标，学习笔记用于记录问题与推理过程。

网页支持逐段聚焦阅读：点击正文段落后，可用 ↑ / ↓ 或阅读栏按钮移动。交互实验直接在浏览器中计算，改变参数可观察例子，但有限次计算不能替代一般证明。Python 实验附录可下载为 Notebook，在本地 Jupyter 中修改和运行。

## 内容标识

定义、定理、命题、引理、推论、例和练习均有文字标识与章节编号。颜色仅辅助区分类型；注释用于解释条件、记号和常见误区。公式中的域元素、它的多项式或幂表示，以及用于存储的整数编码应始终区分。

本书采用 $\mathbb F_q$ 表示含 $q$ 个元素的有限域。有限域实验中使用 $\alpha$ 的幂输入时，会明确指定本原元与域模型；零元素单独选择。有关统一记号与边界条件，可查阅[记号与常用结论](appendices/source.md)。
